# Справочник taskline

Точное описание команд, аргументов и кодов ошибок.
Читатель ищет здесь конкретное значение, а не читает подряд.

## Команды

### `add`

| Поле | Значение |
|---|---|
| Описание | Добавляет задачу в конец списка |
| Аргументы | `текст` (строка, обязательный) |
| Тип | команда |
| По умолчанию | — |
| Ошибка | `аргумент не указан` — «Не указан текст задачи» |
| Пример | `taskline add "Купить хлеб"` |

### `list`

| Поле | Значение |
|---|---|
| Описание | Выводит все задачи с номерами |
| Аргументы | нет |
| Тип | команда |
| По умолчанию | — |
| Ошибка | `файл не найден` — «Список задач пуст» |
| Пример | `taskline list` |

### `done`

| Поле | Значение |
|---|---|
| Описание | Отмечает задачу выполненной |
| Аргументы | `номер` (целое, обязательный) |
| Тип | команда |
| По умолчанию | — |
| Ошибка | `номер вне диапазона` — «Задача не найдена» |
| Пример | `taskline done 2` |

### `remove`

| Поле | Значение |
|---|---|
| Описание | Удаляет задачу из списка |
| Аргументы | `номер` (целое, обязательный) |
| Тип | команда |
| По умолчанию | — |
| Ошибка | `номер вне диапазона` — «Задача не найдена» |
| Пример | `taskline remove 3` |

### `--version`

| Поле | Значение |
|---|---|
| Описание | Выводит версию программы |
| Аргументы | нет |
| Тип | флаг |
| По умолчанию | выключен |
| Ошибка | — |
| Пример | `taskline --version` |

## Коды ошибок

| Код | Сообщение | Когда возникает |
|---|---|---|
| `E001` | «Не указан текст задачи» | `add` вызван без аргумента |
| `E002` | «Список задач пуст» | `list` при отсутствии файла задач |
| `E003` | «Задача не найдена» | `done` / `remove` с несуществующим номером |

## Формат файла задач

| Поле | Значение |
|---|---|
| Путь | `~/.taskline/tasks.txt` |
| Кодировка | `UTF-8` |
| Формат строки | `<номер>. <текст> [x]` |
| Разделитель | перевод строки `\n` |
| Формат даты создания | не установлено (в текущей версии не сохраняется) |
